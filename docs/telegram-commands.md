# دستورهای تلگرام

این ۲۴ دستور در منوی `/` چت خصوصی مالک نمایش داده می‌شوند. هر قابلیت یک دستور دارد؛ انتخاب حالت سریع یا عمیق با دکمه‌های `/mode` انجام می‌شود.

| دستور | کاربرد |
|---|---|
| `/start` | شروع و معرفی |
| `/help` | راهنما |
| `/queue` | کار مستقل بعدی |
| `/new` | گفتگوی تازه |
| `/memory` | حافظه و فایل‌ها |
| `/mode` | انتخاب حالت پاسخ |
| `/files` | مدیریت فایل‌ها |
| `/cookies` | مدیریت کوکی دانلود |
| `/reminders` | یادآورها و زمان‌بندی |
| `/tasks` | کارهای پس‌زمینه |
| `/search` | جستجوی گفتگوهای قبلی |
| `/board` | برد کارها |
| `/dashboard` | داشبورد وب |
| `/settings` | پنل مدیریت |
| `/update` | بروزرسانی از گیت‌هاب |
| `/learn` | مدیریت یادگیری |
| `/teach` | یاد دادن یک درس |
| `/moa` | رأی‌گیری چندمدلی |
| `/approve` | تأیید دستور منتظر |
| `/yolo` | تنظیم تأیید دستورات |
| `/language` | زبان ربات |
| `/id` | شناسه کاربر و گفتگو |
| `/me` | وضعیت حساب و مصرف |
| `/cancel` | توقف کار فعلی |

پس از بروزرسانی و راه‌اندازی مجدد ربات، منو خودکار با نسخهٔ نصب‌شده همگام می‌شود. ثبت منو در فارسی، انگلیسی و زبان پیش‌فرض انجام می‌شود. گروه و کانال پشتیبانی نمی‌شوند.
